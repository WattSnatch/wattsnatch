3

You need to be inside or next to the car to complete this step.
Step 9 of 12
Bluetooth LE Proxy
WattSnatch talks to your car over Bluetooth through Tesla's own open-source TeslaBleHttpProxy. It doesn't have to run on this same machine - anywhere on your LAN within Bluetooth range of the car works, as long as WattSnatch can reach its URL. It reuses the key you already generated in step 7 - no separate pairing needed.
Not practically usable on macOS. TeslaBleHttpProxy needs macOS's CoreBluetooth framework, which refuses to run code that isn't signed with a paid Apple Developer ID certificate - it fails with a silent crash (SIGABRT), not a permission prompt, and no amount of ad-hoc signing or Info.plist changes works around it. Run it on Linux instead - a Raspberry Pi near the car works well - and point the URL below at that machine's LAN address. WattSnatch itself can stay on macOS; only this one proxy needs to be elsewhere.
1
On the Linux machine that will run it: install Go from go.dev/dl (or apt install golang-go) if you don't already have it
2
git clone https://github.com/wimaha/TeslaBleHttpProxy.git && cd TeslaBleHttpProxy && go build
3
Copy the same keys/private.pem WattSnatch generated onto that machine, and run the proxy pointing at it, on the port you enter below
